# jogo-genius
Um jogo de FPGA onde o jogador seleciona uma sequencia de switches on e salva essa sequencia. O jogador 2 deve adivinhar qual a sequencia certa apertando o botão confirmar. Tal botão revela a quantidade de acertos de 0 a 16.
Alunos: Alexandre Padilha, Gionvanni Morandi, Henrique Staubus
  .
. . .
  .          Botao da esquerda salva. Botao do meio é reset. Botao da direita checa.
